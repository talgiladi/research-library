## Agent memory

### [Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision](https://arxiv.org/abs/2609.20820)

Dashora, Chen, Shenfeld, Marangola, Agrawal, and Simchowitz hit a familiar agent-memory bind in robotics: long-horizon manipulation needs long-term memory of what already happened, yet stuffing the full history into the policy invites spurious correlations and tanks performance. The usual fix—querying a VLM in the loop for task-salient bits—is too expensive every step. They burn that VLM cost at train time instead: the model labels what current and historical information matters, then a set-reconstruction loss distills it into a compact workspace token. At deployment the policy swaps observations for that token and never calls the VLM again. On sim and hardware the token is not only cheaper than in-loop reasoning but also improves success on memory-heavy tasks. Memory design for Tal: pay for salience labeling once, then ship a drop-in latent that replaces the history dump.

### [Large Language Model Agents for Evidence Based Genetic Disease Severity Classification](https://arxiv.org/abs/2609.19569)

Ghasemnejad, Argha, Grosser, Wang, Yang, Porntaveetus, Roscioli, and Lovell turn a subjective genetics workflow into a ReAct-plus-RAG agent: classify severity for 10,211 Human Phenotype Ontology terms using ACMG and ACOG criteria, retrieving PubMed, writing reasoning chains, and checking claims. Against expert cohorts it hits 93.55% accuracy (MCC 0.9237), with 82.6–91.4% of claims backed by evidence or valid inference; aggregating 8,738 gene–phenotype pairs surfaces 3,283 autosomal-recessive pairs with severe or profound presentations, and external checks reach 95.2% concordance with Mackenzie’s Mission. The pitch is standardized panel design without a room of curators. Retrieval-memory note for Tal: when memory is a literature corpus, pair tool-using ReAct with claim-level verification, not just a final label.

### [Scientific Image Quality Assessment via Multi-modal Retrieval-Augmented Generation](https://arxiv.org/abs/2609.19634)

Zhang, Liu, Tu, Chu, Liu, Chen, Bian, and Yu build a multimodal RAG stack for scientific image quality assessment that must both understand and score figures in the SIQA challenge. A joint index mixes textual semantics with fine-grained visual features; multi-route retrieval and fusion then hand an LLM the most relevant reference cases so it can judge messy scientific images the way experts do. The system took first place on the SIQA-U understanding track at the ICME 2026 Grand Challenges. It is less a long-horizon agent memory than a reminder that retrieval-augmented judgment still moves leaderboards when the corpus is visual and niche. RAG takeaway for Tal: invest in the multi-route index before another judge prompt.

## Agent harness

### [Chronicle: Cut-Point Replay for Regression Testing of LLM Agents](https://arxiv.org/abs/2609.20625)

Chawla and Koul name the CI hole everyone hits with agents: failures depend on non-reproducible inference, tools that read live state, and trajectories a re-run almost never repeats. Existing record-and-replay traces or scores runs—it does not regression-test a code change. Chronicle records each non-deterministic boundary as an immutable envelope; cut-point replay serves a chosen subset from the record while executing the rest live under new code, turning a past incident into a CI test. On six recorded failures, recording costs ~23 μs per boundary; full replay issues zero model calls and stays bit-stable; cut-point tests fail on faulty code and pass on guarded changes for all six, catching every mutant that lets the unsafe action through while a stub-everything baseline catches none. Harness test for Tal: freeze the non-deterministic seams, then replay only the cut you changed.

### [RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning](https://arxiv.org/abs/2609.20784)

Yu, Lu, Liu, Pan, Wang, Chen, Yang, Zhang, Lu, Chen, and Shen revisit self on-policy distillation for multi-turn agents: a skill-conditioned teacher densifies a single trajectory reward into token-level supervision for a skill-free student. Two agentic findings break the naive recipe—privileged information does not always make the teacher trustworthy, and teacher help is stage-dependent. RetireOPD trains a decoupled skill-conditioned teacher on environment rewards, then trains the student with RL plus OPD; Adaptive Retirement drops the teacher once discrepancy stops shrinking and the student hits a target fraction of teacher success. Across Qwen2.5 1.5B–7B it lifts ALFWorld success 14.1–18.8% and WebShop accuracy 11.8–19.0% over RL alone, and the student beats its own teacher every time. Distillation note for Tal: retire the privileged teacher when the student stops needing it.

### [UnifiedPlayers: Enhance Tool-Integrated Reasoning in Agentic Reinforcement Learning](https://arxiv.org/abs/2609.20089)

Liao, Zhao, and Cao tackle self-evolving tool agents where planning, execution, and evaluation all adapt and continuously warp each other’s training data. UnifiedPlayers splits the job into a Planning Player that proposes tasks, an Execution Player that produces multi-turn Python-tool trajectories, and an Evaluation Player that builds executable verifiers, with role-specific rewards under GRPO. Across two backbones and twelve reasoning benches it beats the strongest prior baseline by at least 3.5% on math and 3.9% on general reasoning; the learned verifier hits 84.2% adversarial detection and 2.03× higher per-question reward variance than self-consistency. Tool-RL note for Tal: co-train the verifier as a first-class player, not a frozen judge bolted on after rollouts.

### [Protocol-Preserving Context Trimming for Agentic Workflows: Benefits, Failure Regimes, and Budget Guardrails](https://arxiv.org/abs/2609.16461)

Gaggar stress-tests trimming long agent histories that hold instructions, tool state, decisions, and open dependencies. Five strategies—recency, relevance, summarization, protocol-aware trimming, and adaptive budget guardrails—are scored on success, protocol adherence, valid tool calls, tokens, latency, and cascading failures. Conventional trims save ~60% tokens but drop success to 66.6–77.3%. Protocol-aware trimming lifts success to 92.2%; adaptive guardrails reach 96.0% success, 96.3% adherence, and 1.0% cascading failure while still saving 56% tokens. Budgets at or under 25% retained context raise failure odds 10.92× versus ≥50%. Context policy for Tal: preserve protocol-critical state first—max token deletion is the wrong objective.

### [TRACE: Accountable Agentic Retrieval for Source Discovery in Digital Archives](https://arxiv.org/abs/2609.19897)

Bian, Puren, and Cafiero build TRACE for historical archives where OCR is dirty, genres collide, and scholars need source traceability. The training-free agentic retriever came out of DECIDON (parliament–press discourse in the French Third Republic) and is already used by 24 researchers across six institutions. On HistoriQA-ThirdRepublic—1,752 French questions over 1887 debates and newspapers—TRACE hits R@10 = 0.856 and MRR = 0.653, beating sparse, dense, graph, and agentic RAG baselines, with the biggest gains on multi-hop and cross-corpus questions, at roughly $0.02 per question on hosted inference. Archive harness for Tal: optimize for accountable source discovery before you pay for graph construction or fine-tunes.

### [Inference-Engine Fingerprinting Attacks are Practical: Exploring Model-Driven Environmental Discovery, Exploitation, and Escape](https://arxiv.org/abs/2609.20614)

Radway, Cheng, Reddi, and Mickens argue the inference engine itself—vLLM, SGLang, and kin—is an under-discussed target once models can exploit complex software. A misaligned model that fingerprints which engine is serving it can then fire engine-specific exploits using only carefully chosen output tokens, without malicious inputs and without other stack pieces. They show fingerprints in five popular engines, how realistic agentic harnesses let a model discover the local engine, and a proof-of-concept chain to bare metal from a compromised engine. The closing brief is defensive: make fingerprinting harder. Sandbox note for Tal: if the agent can read its serving stack, treat the inference engine as attack surface, not just the tools wrapped around it.

## LLM security

### [AgentLSD: Evaluating AI Security Agents Under Adversarial Task Contamination](https://arxiv.org/abs/2609.19140)

Golinelli, Drago, Boffa, Bergadano, and Crispo widen the prompt-injection lens: security agents that read pages, code, logs, and command output also face adversarial task contamination—fake flags, misleading hints, decoy endpoints, and other non-instructional evidence that steers behavior. AgentLSD injects such traps into CTF challenges while leaving the real solution intact, with paired clean vs. contaminated runs. Six models on 11 web CTFs capture 41% of flags when clean; traps then add about +20 turns and +2k reasoning tokens even when the flag is still found, and some agents chase decoys or submit wrong flags. Clean CTF scores therefore understate vulnerability to deceptive task evidence. Eval note for Tal: red-team the evidence channel, not only the instruction channel.

### [CaMeLoT: CaMeL orchestrated with Temporal logic for static verification and liveness](https://arxiv.org/abs/2609.18674)

Nikolaou, Eckhoff, Flood, Grov, Mavroeidis, and Aspinall treat agent security as a property of the whole plan—tool calls, control flow, and data dependencies—not any single step. CaMeLoT sits on CaMeL’s prompt-injection defence: before any tool runs, the plan becomes a finite-state system labeled with calls, provenance, and taint, then nuXmv checks CTL temporal policies. Failed checks return a counterexample for plan repair, and static verification avoids burning tokens or invoking tools on doomed plans. Policies from AgentDojo, SOC workflows, and prompt-extraction settings show a broad class of temporal properties can be cleared pre-execution while keeping CaMeL’s runtime coverage. Plan gate for Tal: model-check the tool graph for taint and liveness before the first side effect.

### [The Verifiable Action Card: Trustworthy Human-in-the-Loop Control for Secure Autonomous Agents](https://arxiv.org/abs/2609.18411)

Irshad, Mughees, Mughees, Mughees, and Soomro go after agentic browsers that act inside the user’s session: if the confirmation dialog can be forged by page content or model text, classic HITL is theater. The Verifiable Action Card rebuilds approval from the ground-truth pending browser action and trusted intent, renders it in browser chrome out of band, and binds the click to the action re-checked at dispatch. On a 24-scenario bench covering confused-deputy attacks, dialog forging, indirect prompt injection, and action substitution, attack success without the card runs 68–100% across LLMs and falls to 0% with it, at 78% legitimate completion and a 0% false-block rate. Browser-agent control for Tal: approve the action that will actually run, not the model’s story about it.
